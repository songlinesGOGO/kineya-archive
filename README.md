# KINEYA static portfolio archive

Prepared from Simply Static export dated 2026-11-24.
This is a non-functional historical showcase, not a live store.

Changes:
- Cart, checkout and account pages removed.
- Add-to-cart controls replaced with an archive label.
- Contact form replaced with an archive notice.
- Product purchasing form and sorting form removed.
- WordPress telemetry references removed where identifiable.
- Most unreferenced WordPress plugin / core files excluded.
- Pages include noindex,nofollow robots directives to avoid appearing as a current shop.

Important limitations:
- Purchases, checkout, login, contact form and server-side WordPress features do not work.
- JavaScript may still contain legacy AJAX / WordPress API calls; browser testing is necessary.
- Some original hyperlinks and embedded third-party resources may still point to the old domain.
- CSS/JS and pages should be verified after upload to GitHub Pages.
- This ZIP is NOT a WordPress/database backup. Keep the original export separately.

Publish on GitHub Pages:
1. Create a public repository, for example 'kineya-archive'.
2. Upload contents of this ZIP (not the ZIP itself) at repository root.
3. Settings > Pages > Deploy from a branch > main > /(root).
4. Test https://YOURUSERNAME.github.io/kineya-archive/
5. Check all pages/images and browser console before cancelling paid hosting.

Original HTML uses relative URLs. Some absolute paths in scripts or other resources may still be incompatible with project subpaths.
